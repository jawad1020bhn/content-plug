# Reference sheet — template

Copy this file to your page folder (or edit it in place) and fill it with **your** niche's reference data.
Every row needs a source. Nothing gets posted from this sheet without a source.

Status values:

- `verified` — checked by the human, in practice, on a date. Safe to post.
- `reported` — listed in at least one published, named source. Post with "reported", not "confirmed".
- `unconfirmed` — not found in any source, or only in an unsourced screenshot. Never post.

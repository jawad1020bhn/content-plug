# Reference cards

One job: take a **sourced reference sheet** and turn it into slides or posts, without inventing a single value.
The sheet lives at `references/reference-sheet.md` in this skill; if the page has its own
`references/reference-sheet.md` (or any sheet the human pasted), use that one instead. The structure is the same
whatever the niche:

```
| item | values | how to use it | status | source |
```

`status` is `verified`, `reported` or `unconfirmed`. Examples of a sheet: game cheat codes, app keyboard
shortcuts, espresso ratios, image-export sizes, camera settings, tax-free thresholds. Adapt the wording of the
carousel to the niche; keep the discipline.

Answer only from the reference sheet. Never add an item from memory.

## Make a 4-slide reference carousel

1. Cover: what the sheet covers + who it is for + one concrete hook line ("The 12 shortcuts everyone misses").
2. How to use: the setup steps from the sheet, plus its one warning (what not to do while using it).
3. Basics: the items people need most often, with the values as big key-caps or chips.
4. Advanced: the long-tail items, the extras, the edge cases.

Style: dark background, one accent color, values as rounded key caps, the page handle on every slide.
Caption: the HOW TO template from the playbook, credit the source named on each sheet line.

## Rules

- Post only items with status `reported` or `verified`. Never post `unconfirmed` ones.
- Before posting, check that each item appears in at least one source listed on the sheet. If it is not listed,
  write "not found yet" and never invent the values.
- Until an item is verified in practice, say "reported" in the caption, not "confirmed".
- No mod menus, exploits, cheats that break a platform's rules, or anything that gets the human's account banned.
- If the sheet is thin, say so and offer a smaller carousel rather than filling the gap from memory.

## Keeping it fresh

When the human tests an item, set its status to `verified` with who tested it and the date. If it fails, mark it
`wrong` and post a correction.

# stream-plug

Workspace running the [gtavi-claudecode](https://github.com/Bodila51/gtavi-claudecode) plugin
(GTA 6 Clip Desk, MIT) — vendored at `gtavi-claudecode/` — adapted to the Arena agent harness.

- **Audit + install notes, and how to run everything here:** see [AGENTS.md](AGENTS.md)
- **First-time / fresh sandbox setup:** `./setup.sh` (recreates `.venv` with all
  requirements plus static ffmpeg/ffprobe)
- Plugin docs: [gtavi-claudecode/README.md](gtavi-claudecode/README.md)
